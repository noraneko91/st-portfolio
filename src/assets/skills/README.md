# スキルのロゴ / 스킬 로고

- 出典 / 출처: [Devicon](https://github.com/devicons/devicon) v2.16.0（`icons/<name>/<name>-original.svg` をそのまま複製 / 그대로 복제）
- ライセンス / 라이선스: MIT（[LICENSE.devicon](LICENSE.devicon)）
- 各ロゴの商標は各社に帰属する / 각 로고의 상표는 각 회사에 귀속된다

Devicon にない VBA・JPA・Struts・HiRDB・UFT One は、サイトの持ち主が用意したロゴ画像から記号の部分を切り出した PNG（64px）を使う。

Devicon에 없는 VBA·JPA·Struts·HiRDB·UFT One은 사이트 주인이 준비한 로고 이미지에서 기호 부분을 잘라낸 PNG (64px)를 쓴다.

ファイル名は `src/content/skills.yaml` の `id` に合わせる。ファイルがないスキル（JSP など）は、名前の頭文字のバッジで表示する。

파일 이름은 `src/content/skills.yaml`의 `id`에 맞춘다. 파일이 없는 스킬 (JSP 등)은 이름 머리글자 배지로 표시한다.
