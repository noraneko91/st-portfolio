- 出典 / 출처: [Devicon](https://github.com/devicons/devicon) v2.16.0（`icons/<name>/<name>-original.svg` をそのまま複製 / 그대로 복제）
- ライセンス / 라이선스: MIT（[LICENSE.devicon](LICENSE.devicon)）
- 各ロゴの商標は各社に帰属する / 각 로고의 상표는 각 회사에 귀속된다

ファイル名は `src/content/skills.yaml` の `id` に合わせる。ファイルがないスキル（JSP・VBA・Struts・JPA・HiRDB・UFT One など）は、名前の頭文字のバッジで表示する。

파일 이름은 `src/content/skills.yaml`의 `id`에 맞춘다. 파일이 없는 스킬 (JSP·VBA·Struts·JPA·HiRDB·UFT One 등)은 이름 머리글자 배지로 표시한다.
