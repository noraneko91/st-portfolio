# プロジェクト概要 — st-portfolio

## 目的

経歴・技術・個人開発を紹介する多言語ポートフォリオサイトを作る。

- 対象読者: 日本・韓国の企業の採用担当者、フリーランス案件の担当者
- 読者が短時間で「何ができる人か」「どう考えて作る人か」を判断できることを重視する
- サイト自体も成果物の一つとして、設計判断を [ADR](adr/) に記録する

## スコープ

### 対象

- 静的サイト（DB・サーバーなし）、モバイルファーストのレスポンシブ対応
- 4言語対応: ja（デフォルト・原文） / en / zh（簡体字） / ko
- ページ: Home / About（経歴） / Skills / Projects / Contact
- ダークモード、言語別フォント、hreflang・言語別 sitemap の出力

### 対象外

- サイト自体のサーバーサイド処理・DB
- サイト自体の AWS 構築（Python + AWS の実績は Projects ページで個人開発として紹介する。理由は [ADR 0001](adr/0001-static-site.md)）

## Projects 詳細ページの構成

各プロジェクトを次の項目で紹介する。

| 項目 | 内容 |
|---|---|
| 概要 | 何を解決するプロジェクトか |
| AWS構成図 | インフラ構成の図 |
| 技術スタック | 使用技術（バージョンを明記） |
| 技術選定理由 | なぜその技術を選んだか、比較した候補 |
| 担当工程 | 要件定義・設計・実装・テスト・運用のうち担当した範囲 |
| 工夫した点・課題と解決 | 直面した課題と、その解決方法 |
| リンク | GitHub・デモGIF・Zenn 記事 |
