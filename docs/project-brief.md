# プロジェクト概要 — st-portfolio

## 目的

経歴・技術・個人開発を紹介する多言語ポートフォリオサイトを作る。

- 対象読者: 日本・韓国で、技術的な経歴やスキルを確認したい企業・プロジェクトの担当者
- 読者が短時間で「何ができる人か」「どう考えて作る人か」を判断できることを重視する
- サイト自体も成果物の一つとして、設計判断を [ADR](adr/) に記録する

## スコープ

### 対象

- 静的サイト（DB・サーバーなし）、モバイルファーストのレスポンシブ対応
- 4言語対応: ja（デフォルト・原文） / en / zh（簡体字） / ko
- ページ: Home / About（自己紹介） / Skills / Projects（業務経歴・個人開発） / Contact（構成の理由は [ADR 0006](adr/0006-projects-work-personal.md)）
- ダークモード、言語別フォント、hreflang・言語別 sitemap の出力

### 対象外

- サイト自体のサーバーサイド処理・DB
- サイト自体の AWS 構築（Python + AWS の実績は Projects ページで個人開発として紹介する。理由は [ADR 0001](adr/0001-static-site.md)）

## Projects の構成

Projects は URL の異なる2つのタブに分ける。`/[lang]/projects/` は業務経歴へ移動する。

| タブ | URL | 内容 |
|---|---|---|
| 業務経歴 | `/[lang]/projects/work/` | 経歴のタイムライン（役割・担当業務・工程・技術） |
| 個人開発 | `/[lang]/projects/personal/` | 個人開発の一覧（分類: 学習 / 制作、状態: 進行中 / 完了） |

個人開発の詳細は `/[lang]/projects/personal/<slug>/` に次の項目で紹介する。

| 項目 | 内容 |
|---|---|
| 概要 | 何を解決するプロジェクトか |
| AWS構成図 | インフラ構成の図 |
| 技術スタック | 使用技術（バージョンを明記） |
| 技術選定理由 | なぜその技術を選んだか、比較した候補 |
| 担当工程 | 要件定義・設計・実装・テスト・運用のうち担当した範囲 |
| 工夫した点・課題と解決 | 直面した課題と、その解決方法 |
| リンク | GitHub・デモ・Zenn 記事（種類と URL を並べ、新しいタブで開く） |

## 技術スタック

| 分類 | 採用技術 | 関連 ADR |
|---|---|---|
| 言語 | TypeScript（strict） | — |
| フレームワーク | Astro | [0002](adr/0002-astro.md) |
| スタイル | Tailwind CSS | — |
| UI 部品 | React islands + shadcn/ui（コマンドパレットのみ） | [0005](adr/0005-react-islands-shadcn.md) |
| ホスティング | Cloudflare Workers（GitHub への push で自動デプロイ） | [0001](adr/0001-static-site.md)・[0004](adr/0004-cloudflare-workers.md) |
| 多言語 | 言語別パス（/ja/ /en/ /zh/ /ko/） | [0003](adr/0003-i18n-path-routing.md) |

バージョンはリポジトリ直下の `CLAUDE.md`「버전 기록」に記録している。
