# 0007. Home をベントーにし、奥行きのある背景とタイルからページへの変形遷移を入れる

## ステータス

承認（2026-10-18）

## 背景

- Home は見出し・ターミナル風の要約・ページ案内のカードを縦に並べており、スクロールしないと全体が見えなかった
- 「何ができる人か」を短時間で伝えるため、Home の 1 画面で各ページの中身の一部（経歴の流れ・スキル・個人開発・連絡先）を見せたい
- サイト自体を成果物として見せるため、モダンで操作して楽しい表現にしたい。ただし Lighthouse 各項目 90 点以上と、文字のコントラストは保つ（CLAUDE.md デザイン原則）
- 背景・遷移・グラフの組み合わせを 3 案（遠近グリッド + ガラス / オーロラ + パララックス + ガラス / 方眼紙 + 影）で試作し、実際に動く状態で比べて決めた

## 決定

- **Home をベントーグリッドにする**
  - タイルはプロフィール / 業務経歴（小さな git graph）/ スキル（伸びるバー）/ 個人開発（最新の表紙）/ お問い合わせ
  - PC では 1 画面に収め、スマートフォンでは縦に積む
- **背景は遠近グリッド（案 A）**
  - CSS の `perspective` で奥に倒した方眼の床と、地平線の光
  - 床は全ページで同じように流す（当初は Home だけだったが、ページ間で背景の印象をそろえるため 2026-10-18 に全ページへ広げた）
  - 装飾なので JS・画像は使わない
- **タイルとページ見出しはすりガラスの面（`.panel`）にする**
  - 背景色を 72% 残し、文字のコントラストは通常の背景と同じ水準に保つ
  - `backdrop-filter` 非対応の環境では不透明の背景にする
- **タイルからページへの変形遷移は、ブラウザ標準のページ間 View Transitions で行う**
  - タイルと各ページの見出しの面に同じ `view-transition-name`（`tile-*`）を付ける
  - URL・戻る操作・検索エンジンへの見え方は通常のページ移動と同じ
  - 非対応ブラウザは通常の移動になる
- **Skills にスキル × 経歴のグラフを置く**
  - 左に経歴と個人開発、右にスキルを並べ、YAML の `tech` から線を引く
  - 選ぶとつながりを強調する。キーボード操作は矢印キー・Enter・Esc（roving tabindex）で、結果は読み上げにも文で知らせる
  - 線を JS で引くため、JS が動かない環境ではグラフを出さない（スキルの一覧は同じページにある）
- **動きは transform のみ**
  - 床の流れ・バー・点の出現は transform だけで動かす
  - `prefers-reduced-motion` ではすべて止め、ページ遷移も即時にする
- **IDE 風の「Dev mode」はデザイン案に留め、実装しない**（必要になったら別の ADR で決める）

## 検討した代替案

### 案 B: オーロラ + マウスパララックス

- 柔らかく色のある印象になる
- 常に動く色のにじみと、マウスに合わせて背景を動かす JS が必要。技術的な印象は A の方が強い

### 案 C: 方眼紙（従来）+ 影のタイル

- 最も軽く控えめ
- 奥行きの表現が弱く、「奥行きのある背景」という目的に合わない

### Three.js などの 3D ライブラリ

- 表現の幅は広い
- 数百 KB の JS が増え、Performance の点数と表示速度に影響する。床の表現は CSS の `perspective` で足りる

### Astro の ClientRouter（SPA 風の遷移）

- 非対応ブラウザでも JS で遷移アニメーションを付けられる
- すべてのページに遷移用の JS が入る。ページ間 View Transitions なら JS なしで同じ表現ができる

### グラフ描画ライブラリ（D3 など）

- 複雑なグラフも描ける
- 2 列の項目を線で結ぶだけなので、TypeScript で直接書く方が軽く、読みやすい

## 結果・トレードオフ

### 利点

- Home の 1 画面でサイト全体の中身が分かり、タイルを押すとそのままページに広がる
- 追加の JS はグラフの部品だけで、Lighthouse は主要 8 ページすべて 100 点（2026-10-18、ローカル・モバイル）

### トレードオフ

- 変形遷移の途中では、面の大きさ（width・height）をブラウザが動かす。自分で書く動きは transform のみ
- Firefox など、ページ間 View Transitions に対応していないブラウザでは変形しない（通常の移動）
- すりガラス（`backdrop-filter`）は描画の負荷が少し増える。使うのはタイルと見出しの面だけにした
- タイル・見出しの面は角丸（14px）で、従来のカード（2px）と角の形が混ざる

## その後の変更（2026-10-19 追記）

この ADR の決定を土台に、運用しながら次の点を変えた。

- **スキルの経験年数とバーをやめた**: 経歴の期間を足した年数は実際の習熟度より長く見えるため、使った経歴・個人開発の件数で示す。Home のスキルタイルも同じ
- **ダークモードの手動切り替え**: ヘッダーの言語ボタンの右にボタンを置き、選んだテーマを保存して `html[data-theme]` で上書きする（描画前に適用）。ライトとダークの明るさの差も少し縮めた
- **見出しの面を小さくし、ドット絵を添えた**: 面の大きさを約 2/3 にし、オリジナルの 16×16 ドット絵（`src/lib/pixel-icons.ts`）を左に置く
- **スキルにロゴ**: Devicon（MIT）の SVG を複製して使う（パッケージは追加しない）
- **個人開発の一覧と Home のタイル**: 大きな表紙をやめ、About のターミナルと同じ雰囲気の小さなウィンドウ型にした
- **Home のプロフィール**: 経験年数などの一覧をやめ、成長の流れ（バックエンド → クラウド → フロントエンド）を図で示す
- **Dev mode**: 引き続き実装しない
